# Anonymous Review Supplementary Website

This repository contains a standalone supplementary website prepared for
double-anonymous peer review. It presents the real-world experiment video
gallery accompanying the paper.

## Local build

Requires Node.js 18 or later and Python 3 for the preview server.

```bash
npm run validate
npm run build
npm run preview
```

Open `http://localhost:8000/`. All site URLs are relative so the generated
`dist/` directory also works when deployed below a GitHub Pages repository path.

## Updating experiment metadata

Edit the source manifest:

```text
public/data/videos.json
```

Use `"success"` or `"failure"` for each `outcome` value. Do not edit
`dist/data/videos.json` directly because `dist/` is generated by the build.

Validate, rebuild, and preview the changes:

```bash
npm run validate
npm run build
npm run preview
```

Then open `http://localhost:8000/` and check the gallery filters, labels,
posters, and video playback.

## Publishing an update

Commit and push the source change to `main`:

```bash
git add public/data/videos.json
git commit -m "Update experiment metadata"

GIT_SSH_COMMAND="ssh -i $HOME/.ssh/id_ed25519_anonymous -o IdentitiesOnly=yes" \
git push origin main
```

Publish the newly generated `dist/` directory to `gh-pages`:

```bash
GIT_SSH_COMMAND="ssh -i $HOME/.ssh/id_ed25519_anonymous -o IdentitiesOnly=yes" \
npx --yes gh-pages@6.3.0 \
  --dist dist \
  --branch gh-pages \
  --dotfiles
```

GitHub Pages must remain configured under **Settings → Pages** with:

```text
Source: Deploy from a branch
Branch: gh-pages
Folder: / (root)
```

Pushing to `gh-pages` automatically starts a new GitHub Pages deployment. There
is no need to unpublish or republish the site. Wait a few minutes, check the
repository's Pages deployment status, and hard-refresh the website with
`Ctrl+Shift+R`.

## Updating Anonymous GitHub

Updating GitHub Pages does not necessarily refresh the Anonymous GitHub mirror
immediately. After confirming the normal GitHub Pages deployment:

1. Open the repository's management page on Anonymous GitHub.
2. Use **Force update** or **Refresh** if automatic updates are disabled.
3. If automatic updates are enabled, allow time for its synchronization cycle.
4. Wait for processing to finish, then hard-refresh the generated `/w/` URL.
5. Verify outcome labels, filters, posters, and videos in a private browser
   window before sharing the reviewer link.

Do not put the identifiable GitHub repository or `github.io` URL in review
materials; share only the `/w/` URL generated by Anonymous GitHub.
